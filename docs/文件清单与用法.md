# gohttpserver · 文件清单与用法

> 配套文档《功能与设计.md》描述架构与功能;本文档列出仓库文件用途,并给出构建、配置、运行方法。

## 1. 源码与配置文件清单

### 1.1 后端 (src/)

> 所有 Go 源码在 `src/` 下(`package main`);`go.mod` / `go.sum` 留在仓库根目录(模块根)。
> 前端资源与测试数据因 `//go:embed` 与测试的相对路径约束,必须随源码一起位于 `src/` 内。

| 文件 | 用途 |
|---|---|
| `src/main.go` | 程序入口:解析 flags 与 `--conf` 配置、构造 `HTTPStaticServer`、注册路由、启动监听 |
| `src/httpstaticserver.go` | 核心:`HTTPStaticServer` 结构体、全部 HTTP handler(`hIndex`/`hUploadOrMkdir`/`hDelete`/`hSave`/`hCopy`/`hMove`/`hZip`/`hPlist`/`hVideoPlayer`/`hJSONList`/`hInfo`/`hSysinfo`)、按目录权限 `.ghs.yml`、搜索索引、模板渲染与 `urlhash` 缓存破坏 |
| `src/ipa.go` | iOS `*.ipa` 安装:解析 Info.plist 生成安装用 plist |
| `src/zip.go` | 目录打包 / 解包(zip) |
| `src/utils.go` | 工具函数(`copyRecursive`、路径/文件判断等) |
| `src/oauth2-proxy.go` | OAuth2 代理支持 |
| `src/openid-login.go` | OpenID 登录实现 |
| `src/assets.go` | `//go:embed assets` 资源内嵌入口(嵌入 `src/assets`) |
| `src/*_test.go` | 单元测试,引用 `src/testdata` |

### 1.2 前端 (src/assets/)

| 文件 | 用途 |
|---|---|
| `src/assets/index.html` | 单页外壳,JS 以 `<script type="module">` + `?v=hash` 方式引入 |

| `src/assets/js/app.js` | 前端主逻辑:状态、列表/网格视图、键盘快捷键 **[定制:默认 list]** |
| `src/assets/js/ui.js` | modal / toast / context menu **[定制:closeModal 可取消]** |
| `src/assets/js/upload.js` | 上传逻辑与进度 **[定制]** |
| `src/assets/js/api.js` | `fetch` 封装(列表/上传/删除/复制/移动等 REST 调用) |
| `src/assets/js/preview.js` | README Markdown 预览 |
| `src/assets/js/theme.js` | 主题切换 |
| `src/assets/js/icons.js` | 文件类型图标 |
| `src/assets/js/util.js` | 前端工具函数(格式化大小/时间、编码等) |
| `src/assets/ipa-install.html` / `src/assets/video-player.html` | 平台功能页 |

### 1.3 构建 / 依赖 / 其他

| 文件 | 用途 |
|---|---|
| `go.mod` / `go.sum` | Go 模块与依赖锁定(声明 `go 1.23.0`,实际用 go1.22 构建时已临时降级) |
| `release/build.sh` | 跨平台交叉编译脚本(输出到 `release/`,无 git 时版本回退为 `dev`) |
| `release/docker/` | Docker 构建文件(`go build ./src`) |
| `release/Procfile` / `release/.goreleaser.yml` / `release/scripts/` | 部署/发布相关 |
| `config.yaml` | **[定制]** 示例配置:端口 11080、upload、delete、admin:admin(位于仓库根) |
| `docs/功能与设计.md` | 功能与设计文档 |
| `docs/文件清单与用法.md` | 本文档 |
| `.ghs.yml` | 运行期约定:放在某目录下,用于覆盖该目录(及子目录)的访问权限 |

## 2. 构建

### 2.1 正常构建(go1.27 环境,通用)
```bash
# 源码在 ./src,模块根仍在仓库根
go build -o release/gohttpserver ./src
# 静态链接(推荐分发)
CGO_ENABLED=0 go build -o release/gohttpserver-static ./src
```

### 2.2 目标机构建(go1.22.2 静态,必选)
目标机(内核 6.8 / EPYC)运行 go1.27 二进制会 `trace int3` 崩溃,必须用 go1.22.2 静态编译:
```bash
# 临时将 go.mod 的 go 指令与高版本依赖降级到 1.22 兼容
sed -i 's/^go 1.23.0$/go 1.22.0/' go.mod
sed -i 's#golang.org/x/net v0.38.0#golang.org/x/net v0.17.0#' go.mod
sed -i 's#golang.org/x/text v0.23.0#golang.org/x/text v0.14.0#' go.mod
GOTOOLCHAIN=local CGO_ENABLED=0 /usr/lib/go-1.22/bin/go build -o release/gohttpserver-1.22 ./src
# 构建后恢复 go.mod / go.sum
```
> 已生成的产物:`gohttpserver-static`(go1.27,通用)、`gohttpserver-1.22`(目标机用)。

## 3. 配置

配置文件为 YAML,通过 `--conf` 指定。键名见 `main.go` 的 `Configure` 结构体。示例 `config.yaml`:

```yaml
addr: ""
port: 11080
root: ./share
title: "Go HTTP File Server"
theme: green
cert: ""          # 与 key 同时填写启用 HTTPS
key: ""
upload: true
delete: true
debug: false
no-index: false
deep-path-max-depth: -1
auth:
  type: http
  http:
    - admin:admin
```

**注意**
- `addr` 优先于 `port`;二者皆空默认 `:8000`
- `auth.http` 为多行 `user:pass` 列表
- 按目录权限:在任意子目录放 `.ghs.yml` 可覆盖其及子目录的 `upload`/`delete`/`users`/`accessTables`

## 4. 运行

```bash
# 用配置文件(推荐);二进制在 release/
./release/gohttpserver-1.22 --conf config.yaml

# 或命令行参数
./release/gohttpserver-1.22 -r ./share -p 11080 --upload --delete \
  --auth-type http --auth-http admin:admin --theme green
```

常用参数速查:

| 参数 | 说明 |
|---|---|
| `-r, --root` | 分享根目录,默认 `./` |
| `-p, --port` | 端口,默认 8000 |
| `-a, --addr` | 监听地址,如 `127.0.0.1:8000` |
| `--upload` | 允许上传 |
| `--delete` | 允许删除 |
| `--auth-type http` + `--auth-http user:pass` | HTTP 基础认证 |
| `--theme` | green / black |
| `--cert` / `--key` | TLS 证书(同时填写启用 HTTPS) |
| `--prefix` | URL 前缀(配合反向代理) |
| `--xheaders` | 部署在 nginx 后设为 true |
| `--conf` | YAML 配置文件路径 |

后台运行:
```bash
nohup ./release/gohttpserver-1.22 --conf config.yaml > ghs.log 2>&1 &
```

## 5. 部署到目标机的步骤

1. 将 `release/gohttpserver-1.22`(及可选 `config.yaml`)拷到目标机
2. 目标机建好 `root` 指定的目录(如 `mkdir -p ./share`)
3. `chmod +x gohttpserver-1.22 && ./gohttpserver-1.22 --conf config.yaml`
4. 浏览器访问 `http://<目标机IP>:11080`,输入 `admin / admin`
5. 前端改过 JS/CSS 后,**重新加载页面**即可(URL 带 `?v=hash` 自动失效缓存)
