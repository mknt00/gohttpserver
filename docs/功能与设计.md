# gohttpserver · 功能与设计

> 本文档基于当前仓库源码(`main.go`、`httpstaticserver.go`、前端 `assets/js/*` 等)整理,描述了 gohttpserver 的功能范围与内部设计。文中标注 **[定制]** 的部分为本次针对目标机环境所做的改动。

---

## 1. 项目定位

gohttpserver 是一个用 Go 编写的**静态文件 HTTP 服务器**,提供 Web 界面浏览、上传、下载、删除、在线编辑等文件管理功能。目标是"开箱即用、单文件部署"——编译出一个二进制即可在任何同架构 Linux 上跑。

核心特点:
- 单一静态二进制,无外部依赖
- 内置 Web UI(文件列表/网格视图、拖拽上传、进度条)
- 支持 HTTP Basic / OpenID / OAuth2 认证
- 支持按目录(`.ghs.yml`)做细粒度权限控制
- 支持 iOS (`*.ipa`) 一键安装、视频播放、Markdown 预览、二维码分享

## 2. 总体架构

```
src/main.go                进程入口:解析 flags/配置文件 → 构造 HTTPStaticServer → 注册路由 → ListenAndServe
  └─ src/httpstaticserver.go   核心:HTTPStaticServer 结构体 + 全部 HTTP handler
        ├─ mux.Router         gorilla/mux 路由表(GET/POST/DELETE/PUT + /-/ 特殊路由)
        ├─ AccessConf         按目录递归的权限配置(.ghs.yml)
        ├─ downloadCounts     内存下载计数
        └─ makeIndex          后台定时构建搜索索引
  └─ src/assets/ (go:embed)       前端资源:index.html + css + js(ES Module)
        ├─ src/assets/js/app.js             前端主逻辑(状态、视图、键盘快捷键)[定制:默认 list]
        ├─ src/assets/js/upload.js          上传 UI + 进度[定制:模拟进度 + 绿色填充 + 关闭保护]
        ├─ src/assets/js/ui.js              modal / toast / context menu [定制:可取消关闭]
        ├─ src/assets/js/api.js             fetch 封装
        ├─ src/assets/js/preview.js         README Markdown 预览
        ├─ src/assets/js/theme.js / icons.js / util.js
```

> 目录约定:Go 模块根(`go.mod`)在仓库根;`src/` 下是 `package main` 及其 `//go:embed assets` 与测试数据 `src/testdata`;`docs/` 放文档;`release/` 放构建脚本与发布产物。

### 关键设计点

1. **资源内嵌(`go:embed assets`)**:所有前端文件在编译期打进二进制,不依赖外部目录。模板通过 `renderHTML` 用 `html/template` 渲染,并用 `urlhash` 模板函数对 JS/CSS 追加 `?v=<sha1前8位>` 做缓存破坏——前端内容一变,URL 就变,浏览器必定重新拉取。

2. **路由设计**:普通路径 `/{path:.*}` 按 HTTP 方法分流:
   - `GET/HEAD` → `hIndex`(渲染页面 / 提供文件 / 列表 JSON / 打包下载 / 复制 / 移动,由 `op` 查询参数区分)
   - `POST` → `hUploadOrMkdir` / `?op=copy` / `?op=move`
   - `DELETE` → `hDelete`
   - `PUT` → `hSave`(在线编辑保存)
   - `/-/` 前缀 → 特殊功能(`/-/assets/`、`/-/ipa/...`、`/-/video-player/...`、`/-/sysinfo`、`/-/stats`)

3. **安全防护**:
   - `getRealPath` 用 `filepath.Clean` 规范化路径,防止 `..` 穿越
   - 全局 `Content-Security-Policy` 收紧到 `'self'`,`frame-ancestors 'none'` 防嵌套
   - 读取配置文件 `.ghs.yml` 本身受 `Delete` 权限保护(防止信息泄露)

4. **性能**:上传使用 `sync.Pool` 复用 32KB 缓冲(`bufPool`),减少 GC 压力;大文件(>32MB)由 Go 运行时落入临时文件再落盘。

5. **认证模型**:全局认证在 `Configure.Auth`(命令行/配置文件);同时支持**按目录**的 `.ghs.yml` 覆盖。`readAccessConf` 自当前目录向上递归合并父目录配置,实现"子目录继承父目录权限"。

## 3. 功能清单

### 3.1 文件浏览
- 目录列表(列表视图 / 网格视图可切换;**[定制] 默认 list**)
- 面包屑导航、排序(名称/大小/修改时间)、搜索(基于后台索引,每 10 分钟重建)
- 文件类型图标、Markdown(`README.md`)实时预览
- 二维码分享当前目录 URL

### 3.2 上传
- 点击或拖拽上传,支持**整文件夹**上传(保留相对路径)
- **[定制] 进度条**:上传开始即模拟增长至 ~88%,真实 `XMLHttpRequest.upload.onprogress` 事件到达后接管,完成时填满 100%;进度条用**绿色**填充(`#4caf50`),`display:block` 修正了 `<span>` 不显示的问题
- **[定制] 关闭保护**:上传进行中点击 × / 遮罩 / Esc 会被拦截并提示,避免"窗口关了但任务还在后台跑、看不见结果"

### 3.3 下载 / 打包
- 单文件下载(`?download=true` 强制附件下载),内存计数
- 目录一键打包为 zip 下载(`?op=archive`)

### 3.4 文件管理
- 新建文件夹(mkdir)
- 重命名、删除(`DELETE`)、复制(`POST ?op=copy`)、移动/改名(`POST ?op=move`)
- 在线编辑文本文件并保存(`PUT`)

### 3.5 认证与权限
- HTTP Basic:`auth.http` 用户列表(`user:pass`)
- OpenID(`auth.openid`)与 OAuth2(`auth.id`/`auth.secret`)登录
- 按目录 `.ghs.yml` 设置 `upload` / `delete` / `users` / `accessTables`(正则允许/拒绝文件访问)
- 默认权限来自全局配置,子目录继承并覆盖

### 3.6 平台特性
- iOS `*.ipa` 安装:`/-/ipa/plist` 生成 plist、`/-/ipa/link` 生成 `itms-services` 安装链接(需 `plistproxy`)
- 视频播放:`/-/video-player`
- 主题切换:green / black / ocean / sunset / forest / dark
- 系统信息 `/-/sysinfo`、统计 `/-/stats`

## 4. 本次定制汇总 [定制]

| 改动 | 文件 | 原因 |
|---|---|---|
| 默认视图改为 list | `assets/js/app.js` | 用户要求默认列表方式 |
| 上传进度模拟 + 绿色填充 + 关闭保护 | `assets/js/upload.js`、`assets/css/style.css`、`assets/js/ui.js` | 进度条无反馈 / 关闭窗口丢失任务 |
| 进度条 `display:block` | `assets/css/style.css` | `<span>` 是 inline,`width/height` 不生效 |
| 可取消的 `closeModal` | `assets/js/ui.js` | 支持上传中拦截关闭 |
| 目标机兼容构建 | `go1.22.2` 静态编译 | 目标机跑 go1.27 二进制会 `int3` 崩溃 |

---

## 5. 适用环境与限制

- **部署目标机**(内核 6.8 / EPYC,疑似 VM):只能用 **go1.22.2 静态编译**的二进制(`gohttpserver-1.22`),go1.27 二进制启动即 `trace int3` 崩溃。
- 后台搜索索引默认每 10 分钟重建一次,大目录首次访问可能延迟可见。
- `delete:true` 开启后授权用户可网页删除文件,仅建议在可信网络使用。
